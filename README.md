# AvitoMonitor

Консольная программа на C# (.NET 8), которая следит за Авито вместо вас:

- собирает все объявления по вашему поиску и считает **рыночную цену (медиану)** по группам: iPhone по объёму памяти, квартиры по числу комнат (цена за м²), машины по году;
- круглосуточно отслеживает **новые объявления** и присылает их в **Telegram** с оценкой: на сколько процентов дешевле рынка;
- предупреждает о **подозрительно дешёвых** объявлениях (возможный обман), о битых и заблокированных телефонах, о просьбах внести предоплату;
- распознаёт **копии** («Оригинал» в кавычках, Luxe, Premium, Airoha) и **другие модели** (искали AirPods 4 — попались AirPods Pro) и не учитывает их в рыночной цене;
- вычисляет **магазины под видом частников** и **агентов под видом собственников**;
- строит **таблицу Excel** со всеми объявлениями и отдельными листами «Частники» и «Магазины».

## Быстрый старт

Нужно: Windows 10/11 (Microsoft Edge там уже есть) и [.NET SDK 8](https://dotnet.microsoft.com/download) или новее.

```bash
dotnet run --project src/AvitoMonitor
```

Или откройте `AvitoProject.sln` в Rider и запустите проект `AvitoMonitor`.

Дальше:

1. **Настройки → Подключить Telegram-бота** (см. ниже). Без Telegram программа тоже работает, но уведомления будут видны только в консоли.
2. Откройте Авито в браузере, настройте поиск и фильтры, скопируйте ссылку.
3. **Новый поиск по ссылке** → вставьте ссылку → **«Сначала сканировать, потом следить»**.

Программа откроет отдельное окно Edge и будет листать в нём Авито. Если Авито попросит подтвердить, что вы не робот, пройдите проверку в этом окне сами: программа подождёт и продолжит.

## Режимы работы

| Режим | Что происходит |
|---|---|
| **Сканировать** | Собирает все объявления по ссылке, показывает медианы по группам и строит таблицу Excel |
| **Следить** | Раз в 5 минут (настраивается) проверяет выдачу по дате и присылает новые объявления в Telegram |
| **Дособрать** | Продолжает сканирование с места остановки (после Ctrl+C или ошибки) |
| **Мультипоиск** | Несколько ссылок в одном поиске (например, iPhone 15, 16 и 17); цены сравниваются внутри каждой ссылки |

Ctrl+C во время сканирования или слежения останавливает только текущую операцию и возвращает в меню.

## Подключение Telegram-бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Задайте имя бота и логин (логин должен заканчиваться на `bot`).
3. Скопируйте токен вида `1234567890:AAH...`. Никому его не показывайте.
4. В программе: **Настройки → Подключить Telegram-бота**, вставьте токен.
5. Откройте своего бота и нажмите «Запустить» (`/start`). Программа сама определит чат и пришлёт «✅ AvitoMonitor подключён».

Если токен утёк: @BotFather → `/mybots` → бот → **API Token → Revoke current token**, затем подключите новый токен.

## Где хранятся данные

В папке `Документы\AvitoMonitor`, не в репозитории: так токен бота никогда не попадёт в git.

```
Документы\AvitoMonitor\
  settings.json        — настройки и токен бота
  searches\<id>\       — поиск: ссылки, собранные объявления (JSON), report.xlsx
  browser-profile\     — профиль браузера программы (cookies Авито)
  debug\               — HTML страниц, на которых не нашлось объявлений
  errors.log           — журнал ошибок
```

Папку можно поменять переменной окружения `AVITO_MONITOR_DATA`.

## Если что-то не работает

- **«Доступ ограничен: проблема с IP» / постоянная проверка «я не робот».** Чаще всего виноват VPN: выключите его или добавьте `avito.ru`, `www.avito.ru`, `m.avito.ru`, `avito.st` в исключения (раздельное туннелирование). Не включайте скрытый режим браузера и увеличьте паузу между страницами в настройках.
- **Браузер не запускается.** Проверьте, что установлен Microsoft Edge, или выберите Chrome в «Настройки → Выбрать браузер». Для Chromium от Playwright выполните `pwsh src/AvitoMonitor/bin/Debug/net8.0/playwright.ps1 install chromium` после сборки.
- **Telegram: `Unauthorized`** — неверный токен; **`bot was blocked by the user`** — откройте бота и нажмите «Запустить».
- Подробности ошибок — в `Документы\AvitoMonitor\errors.log`.

## Важно знать

- Авито не любит автоматический сбор данных. Программа работает медленно (пауза между страницами, по умолчанию 8 секунд), проверку «я не робот» не обходит, а ждёт, пока вы пройдёте её сами. Используйте программу для личных целей и не ставьте слишком частые проверки. Ответственность за соблюдение правил Авито лежит на вас.
- Номер телефона продавца программа не получает: в уведомлении есть ссылка на объявление и черновик сообщения продавцу.
- Если Авито поменяет вёрстку, может понадобиться поправить селекторы в `src/AvitoMonitor/Avito/AvitoPageParser.cs`. HTML страниц, на которых не нашлось объявлений, программа сохраняет в папку `debug`.
- Проект собран под `net8.0`. Поддержка .NET 8 заканчивается в ноябре 2026 года. Чтобы перейти на .NET 10, установите SDK 10 и поменяйте `TargetFramework` на `net10.0` в обоих `.csproj`.
