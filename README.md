# AvitoMonitor

Приложение для Windows (C#, .NET 8, Avalonia), которое следит за Авито вместо вас:

- ищет по **ключевым словам** («airpods 4») в выбранном городе, с ценой «от» и «до»: ссылку на Авито составляет само;
- собирает все объявления и считает **рыночную цену (медиану)** по группам: телефоны по объёму памяти, наушники с шумоподавлением и без, квартиры по числу комнат (цена за м²), машины по году;
- круглосуточно отслеживает **новые объявления** и присылает их в **Telegram** с оценкой: на сколько процентов дешевле рынка;
- предупреждает о **подозрительно дешёвых** объявлениях (возможный обман), о битых и заблокированных телефонах, о просьбах внести предоплату;
- распознаёт **копии** («Оригинал» в кавычках, Luxe, Premium, Airoha) и **другие модели** (искали AirPods 4 — попались AirPods Pro) и не учитывает их в рыночной цене;
- вычисляет **магазины под видом частников** и **агентов под видом собственников**;
- хранит всё в **PostgreSQL**, а **историю запросов** дополнительно индексирует в **Elasticsearch**, поэтому поиск по ней понимает опечатки;
- после каждого сбора сохраняет **Excel-отчёт**, а записи об отчётах хранит в базе.

## Быстрый старт

Нужно:
- Windows 10/11 (Microsoft Edge там уже есть);
- [.NET SDK 8](https://dotnet.microsoft.com/download) или новее;
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) для баз данных.

1. Запустите Docker Desktop, затем в папке проекта поднимите базы:

   ```bash
   docker compose up -d
   ```

   Поднимутся PostgreSQL (`127.0.0.1:5433`) и Elasticsearch (`127.0.0.1:9200`). Данные хранятся в томах Docker и не пропадают после перезапуска.

2. Запустите приложение:

   ```bash
   dotnet run --project src/AvitoMonitor.Desktop
   ```

   Или откройте `AvitoProject.sln` в Rider и запустите проект `AvitoMonitor.Desktop`. При первом запуске приложение само создаст таблицы в базе (миграции EF Core).

3. Слева в форме **«Что ищем на Авито»** напишите запрос, выберите город и при желании цену, нажмите **«Найти»** (или Enter).

Откроются два окна: приложение и консоль с журналом работы. Для слежения за Авито приложение откроет отдельное окно Edge. Если Авито попросит подтвердить, что вы не робот, сверху появится жёлтая полоса: пройдите проверку в окне браузера сами, работа продолжится автоматически.

## Окно приложения

| Вкладка | Что там |
|---|---|
| **Поиски** | Слева — форма поиска (слова, город, цена от/до, категория, «после сбора следить за новыми») и список поисков. Подсказки под полем берутся из истории. Справа — выбранный поиск с вкладками ниже |
| ↳ Объявления | Таблица всех объявлений: цена, медиана группы, отклонение от рынка (зелёный — дешевле), пометки, продавец, отзывы, тип продавца. Фильтры и сортировка, кнопка «Открыть» — объявление в браузере |
| ↳ Рынок | Медиана, минимум и максимум по группам; сколько копий, других моделей и выбросов не учтено |
| ↳ Изменить поиск | Название, категория и запросы (слова, город, цена). Можно добавить несколько запросов (мультипоиск) или удалить поиск |
| **Новые объявления** | Лента того, что нашло слежение (то же уходит в Telegram) |
| **История запросов** | Всё, что вводили в поиск, со счётчиком использований. Поиск по истории с опечатками, кнопки «В поле поиска» и «Искать снова» |
| **Отчёты** | Все Excel-отчёты из базы: дата, поиск, что искали, число объявлений, рыночные цены. Кнопки «Открыть» и «Удалить» |
| **Журнал** | Что делает приложение. То же самое пишется в консоль и в файлы `logs\avito-ГГГГ-ММ-ДД.log` |
| **Настройки** | Telegram, паузы, интервал проверки, порог «подозрительно дёшево», браузер, состояние баз данных |

### Что происходит после «Найти»

1. Запрос сохраняется в историю: в PostgreSQL и в индекс Elasticsearch.
2. Создаётся поиск. Если точно такой же уже есть, используется он, дубликат не появляется.
3. Приложение собирает все объявления и считает рыночные цены.
4. Сохраняется Excel-отчёт: файл с датой в имени в папке `reports`, запись о нём — в таблице `reports` базы. Он сразу виден на вкладке «Отчёты».
5. Если стоит галочка «После сбора следить за новыми», включается слежение.

### Кнопки поиска

| Кнопка | Что делает |
|---|---|
| **Сканировать и следить** | Собирает все объявления, сохраняет отчёт и включает слежение |
| **Сканировать заново** | Собирает все объявления с первой страницы и сохраняет отчёт |
| **Дособрать** | Продолжает сбор с места остановки |
| **Следить** | Раз в 5 минут (настраивается) проверяет новые объявления и присылает их в Telegram |
| **Стоп** | Останавливает сбор или слежение |
| **Открыть в Excel** | Создаёт новый отчёт прямо сейчас и открывает его |

Несколько поисков могут работать одновременно, страницы Авито при этом всё равно открываются по одной. Если закрыть приложение во время слежения, при следующем запуске оно продолжится само.

### Что происходит при изменении поиска

- **Переименовали** поиск или запрос — собранные объявления остаются.
- **Поменяли слова, город или цену** — объявления по старому запросу удаляются, сбор начнётся с первой страницы.
- **Удалили запрос** — удаляются и его объявления.
- **Удалили поиск** — объявления удаляются, а отчёты остаются на вкладке «Отчёты».

Пока идёт сбор или слежение, сохранить изменения нельзя: сначала нажмите «Стоп».

## Подключение Telegram-бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Задайте имя бота и логин (логин должен заканчиваться на `bot`).
3. Скопируйте токен вида `1234567890:AAH...`. Никому его не показывайте.
4. В приложении: **Настройки → Telegram**, вставьте токен, нажмите «Подключить».
5. Нажмите «Открыть бота» и в Telegram нажмите «Запустить» (`/start`). Приложение само определит чат и пришлёт «✅ AvitoMonitor подключён».

Если токен утёк: @BotFather → `/mybots` → бот → **API Token → Revoke current token**, затем подключите новый токен.

## Где хранятся данные

| Что | Где |
|---|---|
| Поиски, объявления, история запросов, записи об отчётах | PostgreSQL, база `avito` (таблицы `searches`, `search_sources`, `listings`, `search_queries`, `reports`) |
| Индекс истории для поиска с опечатками | Elasticsearch, индекс `avito-queries` (при запуске досинхронизируется из PostgreSQL) |
| Excel-отчёты | `Документы\AvitoMonitor\reports\` |
| Настройки и токен бота | `Документы\AvitoMonitor\settings.json` |
| Журнал, профиль браузера, отладочный HTML | `Документы\AvitoMonitor\logs\`, `browser-profile\`, `debug\` |

Если у вас остались поиски от прежней версии в JSON-файлах (`Документы\AvitoMonitor\searches\`), при первом запуске они автоматически перенесутся в PostgreSQL.

Адреса баз задаются в `settings.json` (`DatabaseConnectionString`, `ElasticsearchUrl`). Пароль PostgreSQL по умолчанию подходит только для локальной базы. Чтобы поменять его, создайте рядом с `docker-compose.yml` файл `.env` со строкой `POSTGRES_PASSWORD=...` (этот файл в git не попадает) и укажите тот же пароль в `settings.json`. Если Elasticsearch не запущен, приложение работает, а история ищется по PostgreSQL.

## Как устроен код

```
src/AvitoMonitor.Core/        — вся логика, без интерфейса (библиотека)
  Domain/                     — модели: Listing, SavedSearch, ListingAssessment, ReportRecord
  Avito/                      — браузер (Playwright + Edge), разбор HTML, ссылки, SearchRequest и города
  Analysis/                   — медиана, группы, копии, другие модели, пометки, тип продавца
  Persistence/                — PostgreSQL: AvitoDbContext (EF Core), таблицы, миграции, перенос из JSON
  Storage/                    — ISearchStore и его реализация на PostgreSQL, общий каталог поисков
  History/                    — история запросов: PostgreSQL + индекс Elasticsearch (REST API)
  Telegram/                   — Bot API на HttpClient, формат сообщений
  Export/                     — Excel (ClosedXML) и отчёты в базе
  Workflows/                  — сканирование, слежение, редактирование поиска,
                                MonitorService — фоновые задачи по всем поискам
src/AvitoMonitor.Desktop/     — окно на Avalonia (MVVM, CommunityToolkit.Mvvm)
  AppHost.cs                  — сборка служб (Generic Host + DI), подготовка базы
  Logging/                    — журнал: консоль + файл + вкладка «Журнал»
  ViewModels/, Views/         — модели представления и разметка окна
tests/AvitoMonitor.Tests/     — xUnit-тесты
docker-compose.yml            — PostgreSQL 17 и Elasticsearch 8
```

Новая миграция после изменения таблиц:

```bash
dotnet ef migrations add ИмяМиграции --project src/AvitoMonitor.Core --output-dir Persistence/Migrations
```

## Тесты

```bash
dotnet test
```

Интеграционные тесты на настоящих базах запускаются, только если заданы переменные окружения. Они используют отдельную базу `avito_test` и индекс `avito-queries-test` и рабочие данные не трогают:

```powershell
$env:AVITO_TEST_DB = "Host=localhost;Port=5433;Database=avito_test;Username=avito;Password=avito_local"
$env:AVITO_TEST_ELASTIC = "http://localhost:9200"
dotnet test
```

## Если что-то не работает

- **«Не удалось подключиться к базе данных PostgreSQL»** при запуске. Запустите Docker Desktop и выполните `docker compose up -d` в папке проекта, затем откройте приложение снова.
- **«Доступ ограничен: проблема с IP» / постоянная проверка «я не робот».** Чаще всего виноват VPN: выключите его или добавьте адреса Авито в исключения (раздельное туннелирование). Надёжнее исключить подсеть `176.114.120.0/21`, а не только домены. Не включайте скрытый режим браузера и увеличьте паузу между страницами в настройках.
- **Браузер не запускается.** Проверьте, что установлен Microsoft Edge, или выберите Chrome в настройках. Для Chromium от Playwright после сборки выполните `pwsh src/AvitoMonitor.Desktop/bin/Debug/net8.0/playwright.ps1 install chromium`.
- **Telegram: `Unauthorized`** — неверный токен; **`bot was blocked by the user`** — откройте бота и нажмите «Запустить».
- Подробности ошибок — во вкладке «Журнал» и в `Документы\AvitoMonitor\logs\`.

## Важно знать

- Авито не любит автоматический сбор данных. Приложение работает медленно (пауза между страницами, по умолчанию 8 секунд), проверку «я не робот» не обходит, а ждёт, пока вы пройдёте её сами. Используйте приложение для личных целей и не ставьте слишком частые проверки. Ответственность за соблюдение правил Авито лежит на вас.
- Номер телефона продавца приложение не получает: в уведомлении есть ссылка на объявление и черновик сообщения продавцу.
- Если Авито поменяет вёрстку, может понадобиться поправить селекторы в `src/AvitoMonitor.Core/Avito/AvitoPageParser.cs`.
- Проект собран под `net8.0` и Avalonia 11.3. Поддержка .NET 8 заканчивается в ноябре 2026 года. Чтобы перейти на .NET 10, установите SDK 10 и поменяйте `TargetFramework` на `net10.0` во всех `.csproj` (и обновите пакеты EF Core / Npgsql до 10.x).
