# AvitoMonitor

Приложение для Windows (C#, .NET 8, Avalonia), которое следит за Авито вместо вас:

- собирает все объявления по вашему поиску и считает **рыночную цену (медиану)** по группам: телефоны по объёму памяти, наушники с шумоподавлением и без, квартиры по числу комнат (цена за м²), машины по году;
- круглосуточно отслеживает **новые объявления** и присылает их в **Telegram** с оценкой: на сколько процентов дешевле рынка;
- предупреждает о **подозрительно дешёвых** объявлениях (возможный обман), о битых и заблокированных телефонах, о просьбах внести предоплату;
- распознаёт **копии** («Оригинал» в кавычках, Luxe, Premium, Airoha) и **другие модели** (искали AirPods 4 — попались AirPods Pro) и не учитывает их в рыночной цене;
- вычисляет **магазины под видом частников** и **агентов под видом собственников**;
- показывает всё в таблицах с фильтрами и выгружает в **Excel**.

## Быстрый старт

Нужно: Windows 10/11 (Microsoft Edge там уже есть) и [.NET SDK 8](https://dotnet.microsoft.com/download) или новее.

```bash
dotnet run --project src/AvitoMonitor.Desktop
```

Или откройте `AvitoProject.sln` в Rider и запустите проект `AvitoMonitor.Desktop`.

Откроются два окна: само приложение и консоль с журналом работы.

1. **Настройки → Telegram**: подключите бота (см. ниже). Без Telegram приложение тоже работает, новые объявления видны во вкладке «Новые объявления».
2. Откройте Авито в браузере, настройте поиск и фильтры, скопируйте ссылку.
3. **Поиски → Новый поиск**: вставьте ссылку и нажмите «Добавить поиск». Проверьте название и категорию на вкладке «Изменить поиск».
4. Нажмите **«Сканировать и следить»**.

Приложение откроет отдельное окно Edge и будет листать в нём Авито. Если Авито попросит подтвердить, что вы не робот, сверху появится жёлтая полоса. Пройдите проверку в окне браузера сами, работа продолжится автоматически.

## Окно приложения

| Вкладка | Что там |
|---|---|
| **Поиски** | Слева — список поисков и поле для новой ссылки. Справа — выбранный поиск: кнопки, статус и три вкладки ниже |
| ↳ Объявления | Таблица всех объявлений: цена, медиана группы, отклонение от рынка (зелёный — дешевле), пометки, продавец, отзывы, тип продавца. Фильтры: текст, «скрыть копии и другие модели», «только частники», «только дешевле рынка». Сортировка по клику на заголовок, кнопка «Открыть» — объявление в браузере |
| ↳ Рынок | Медиана, минимум и максимум по группам; сколько копий, других моделей и выбросов не учтено |
| ↳ Изменить поиск | Название, категория и ссылки. Можно поменять ссылку, добавить или удалить ссылки (мультипоиск), удалить поиск |
| **Новые объявления** | Лента того, что нашло слежение (то же уходит в Telegram) |
| **Журнал** | Что делает приложение: какие страницы открыты, что найдено, ошибки. То же самое пишется в консоль и в файлы `logs\avito-ГГГГ-ММ-ДД.log` |
| **Настройки** | Telegram, паузы, интервал проверки, порог «подозрительно дёшево», браузер |

### Кнопки поиска

| Кнопка | Что делает |
|---|---|
| **Сканировать и следить** | Собирает все объявления, считает рыночные цены и сразу включает слежение |
| **Сканировать заново** | Собирает все объявления с первой страницы |
| **Дособрать** | Продолжает сбор с места остановки |
| **Следить** | Раз в 5 минут (настраивается) проверяет новые объявления и присылает их в Telegram |
| **Стоп** | Останавливает сбор или слежение |
| **Открыть в Excel** | Строит таблицу `report.xlsx` и открывает её |

Несколько поисков могут работать одновременно, страницы Авито при этом всё равно открываются по одной. Если закрыть приложение во время слежения, при следующем запуске оно продолжится само.

### Что происходит при изменении поиска

- **Переименовали** поиск или ссылку — собранные объявления остаются.
- **Поменяли ссылку** — объявления по старой ссылке удаляются, сбор начнётся с первой страницы.
- **Удалили ссылку** — удаляются и её объявления.
- **Поменяли категорию** — данные остаются, рынок пересчитывается по новым правилам.

Пока идёт сбор или слежение, сохранить изменения нельзя: сначала нажмите «Стоп».

## Подключение Telegram-бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Задайте имя бота и логин (логин должен заканчиваться на `bot`).
3. Скопируйте токен вида `1234567890:AAH...`. Никому его не показывайте.
4. В приложении: **Настройки → Telegram**, вставьте токен, нажмите «Подключить».
5. Нажмите «Открыть бота» и в Telegram нажмите «Запустить» (`/start`). Приложение само определит чат и пришлёт «✅ AvitoMonitor подключён».

Если токен утёк: @BotFather → `/mybots` → бот → **API Token → Revoke current token**, затем подключите новый токен.

## Где хранятся данные

В папке `Документы\AvitoMonitor`, не в репозитории: так токен бота никогда не попадёт в git.

```
Документы\AvitoMonitor\
  settings.json        — настройки и токен бота
  searches\<id>\       — поиск: ссылки, собранные объявления (JSON), report.xlsx
  logs\                — журнал работы по дням
  browser-profile\     — профиль браузера приложения (cookies Авито)
  debug\               — HTML страниц, на которых не нашлось объявлений
```

Папку можно поменять переменной окружения `AVITO_MONITOR_DATA`.

## Как устроен код

```
src/AvitoMonitor.Core/        — вся логика, без интерфейса (библиотека)
  Domain/                     — модели: Listing, SavedSearch, ListingAssessment
  Avito/                      — браузер (Playwright + Edge), ссылки, разбор HTML (AngleSharp)
  Analysis/                   — медиана, группы, копии, другие модели, пометки, тип продавца
  Storage/                    — поиски и объявления в JSON, общий каталог поисков
  Telegram/                   — Bot API на HttpClient, формат сообщений
  Export/                     — Excel (ClosedXML)
  Workflows/                  — сканирование, одна проверка слежения, редактирование поиска,
                                MonitorService — фоновые задачи по всем поискам
src/AvitoMonitor.Desktop/     — окно на Avalonia (MVVM, CommunityToolkit.Mvvm)
  AppHost.cs                  — сборка служб (Generic Host + DI)
  Logging/                    — журнал: консоль + файл + вкладка «Журнал»
  ViewModels/, Views/         — модели представления и разметка окна
tests/AvitoMonitor.Tests/     — xUnit-тесты логики
```

Окно работает только через `MonitorService` и события. Вся логика, включая анализ, лежит в `Core` и проверяется тестами без запуска интерфейса.

## Если что-то не работает

- **«Доступ ограничен: проблема с IP» / постоянная проверка «я не робот».** Чаще всего виноват VPN: выключите его или добавьте адреса Авито в исключения (раздельное туннелирование). Надёжнее исключить подсеть `176.114.120.0/21`, а не только домены. Не включайте скрытый режим браузера и увеличьте паузу между страницами в настройках.
- **Браузер не запускается.** Проверьте, что установлен Microsoft Edge, или выберите Chrome в настройках. Для Chromium от Playwright после сборки выполните `pwsh src/AvitoMonitor.Desktop/bin/Debug/net8.0/playwright.ps1 install chromium`.
- **Telegram: `Unauthorized`** — неверный токен; **`bot was blocked by the user`** — откройте бота и нажмите «Запустить».
- Подробности ошибок — во вкладке «Журнал» и в `Документы\AvitoMonitor\logs\`.

## Важно знать

- Авито не любит автоматический сбор данных. Приложение работает медленно (пауза между страницами, по умолчанию 8 секунд), проверку «я не робот» не обходит, а ждёт, пока вы пройдёте её сами. Используйте приложение для личных целей и не ставьте слишком частые проверки. Ответственность за соблюдение правил Авито лежит на вас.
- Номер телефона продавца приложение не получает: в уведомлении есть ссылка на объявление и черновик сообщения продавцу.
- Если Авито поменяет вёрстку, может понадобиться поправить селекторы в `src/AvitoMonitor.Core/Avito/AvitoPageParser.cs`.
- Проект собран под `net8.0` и Avalonia 11.3. Поддержка .NET 8 заканчивается в ноябре 2026 года. Чтобы перейти на .NET 10, установите SDK 10 и поменяйте `TargetFramework` на `net10.0` во всех `.csproj`.
